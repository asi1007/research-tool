# /check-size

Amazon の商品と 1688 の仕入先候補が**同じサイズか**を突き合わせる。

サイズが違えば別商品で、原価も価格も成立しない。カード価格が最安サイズのものである以上
（`/find-supplier` の「カード価格はほぼ当てにならない」を参照）、**規格を決める前に必ず通す。**

寸法の抽出と比較は `check_size.py` がやる。claude が判断するのは
**寸法がどこに書いてあるか**と、**差が許容範囲か**だけ。

## 手順

```bash
cd marketar/research-tool
.venv/bin/python check_size.py <ASIN> --supplier-text "<1688側の規格名・属性・説明文>"
```

仕入先側のテキストは、次の順に探して**見つかった時点で止める**。

| # | 探す場所 | 取り方 |
|---|---|---|
| 1 | 規格名（`SKU`）| `scripts/extract_variants.js` の戻り値。`G20银色-180°` `2.5*910cm` など |
| 2 | 属性欄・本文 | ページの `innerText` から `尺寸` `规格` `材质` の周辺 |
| 3 | **商品説明画像** | 下記「画像を読む」 |

判定は4つ。`一致` `一部だけ一致` `不一致` `判定不能`。
**`判定不能` は「寸法が無い」であって「合わない」ではない。** 画像まで見てから結論を出す。

## 寸法は規格表に無いことが多い。画像に書いてある

1688 は寸法を**商品説明画像に焼き込む**店が多い。テキストをいくら探しても出てこない。

実例（[1031126018032](https://detail.1688.com/offer/1031126018032.html) 透明吊片）: 規格は
`【10个】【100个】【200个】【300个】` と**個数だけ**。属性欄も `材质:塑料/树脂` のみ。
寸法は説明画像に `高约16毫米` `宽约8毫米` `吊孔直径约2.3毫米` と書かれていた。

```js
// 説明画像のURLを集める（先頭の svg はアイコンなので落とす）
[...new Set([...document.querySelectorAll('img')]
  .map(i => i.getAttribute('src') || i.getAttribute('data-src') || '')
  .filter(u => /cbu01\.alicdn\.com/.test(u))
  .map(u => u.startsWith('//') ? 'https:' + u : u)
  .map(u => u.replace(/_\d+x\d+.*\.(jpg|png|webp)$/i, '')))]
```

`curl` で落として Read で読む。**上から3枚で足りることがほとんど**（寸法図は冒頭に置かれる）。

## 差をどう見るか

CLI は次の基準で自動判定する。**この範囲を手で覆さない。**

- 許容差は **絶対値 0.3mm と 相対 5% の大きいほう**
- 小さい寸法は絶対値で見る（穴径 2.5mm と 2.3mm は同じ型）
- 大きい寸法は割合で見る（100mm と 103mm は同じ型）

`一部だけ一致` が返ったら、**合わなかった寸法が本質的な差かを見る。**

| 合わない寸法 | 判断 |
|---|---|
| 全長・直径・幅 | **別サイズ。書かない**か、合う規格を選び直す |
| 穴径・厚み・肉厚 | 実測ばらつきのことが多い。他が揃っていれば採用し、規格欄に両方の値を残す |
| 個数・入数 | サイズの問題ではない。`quantity` で吸収する |

## 入数も一緒に出る

`入数` 行に Amazon側と1688側の個数が並ぶ。`/find-supplier` の `quantity` を決める材料になる。

```
入数   : Amazon [100] / 仕入先 [10, 100, 200, 300]
```

100個どうしが選べるので `quantity` は 1。**Amazon側に無い数しか無ければ按分する**
（`/find-supplier` の「1688のパックがAmazonの入数より多いときは按分する」）。

## Amazon側の寸法が取れないとき

`Amazon : （取れず）` が出たら、箇条書きに寸法が書かれていない商品。

- **`packageLength` などの梱包寸法は使えない。** 100個入りの袋の寸法であって、部品の寸法ではない
- 商品ページの画像か、競合の同等品から拾う
- どうしても分からなければ**規格を確定しない**。URLだけ書いて価格は空にする

## 注意

- **ラベルの言葉は突き合わせない。** 日本語の「長さ」と中国語の「高」が同じ寸法を指すことがある。
  CLI は**値だけ**で照合する
- **cm と mm が混在する。** CLI が mm へ揃えるので、そのまま渡してよい
- `--json` で機械可読な形になる。他のCLIから呼ぶときはこちら
- 終了コードは `一致`／`一部だけ一致` が 0、`不一致`／`判定不能` が 1
